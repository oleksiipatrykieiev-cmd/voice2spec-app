# Voice2Spec Control Panel

Мобильный веб-виджет и пульт управления для генерации, структурирования и контроля технических заданий в экосистеме VEI. Приложение связывает голосовой поток мыслей, визуальные данные (скриншоты) и репозиторий GitHub для автоматической постановки задач ИИ-агентам (в VS Code / Cursor).

## Основной функционал

* **Преобразование мыслей в ТЗ:** Перевод неструктурированного голосового или текстового ввода в древовидные Markdown-задачи (Эпик -> Логика -> Подзадачи).
* **Мультимодальный ввод:** Поддержка загрузки изображений и скриншотов интерфейса. Файлы загружаются в репозиторий, а ИИ анализирует их для формирования точных технических требований.
* **Управление модулями:** Создание и переключение между разными ветками/модулями проекта (VEI LINK, VEI SCAN и т.д.). Каждая ветка — отдельный `.md` файл в директории `docs/`.
* **Интерактивный менеджер задач:** 
  * Чтение текущих задач напрямую из GitHub.
  * `[ ]` / `[x]` — переключение статуса выполнения.
  * `✏️` — редактирование формулировки задачи.
  * `🗑️` — полное удаление невыполненной задачи.
  * `↩️` — безопасный откат (маркировка выполненной задачи флагом `ОТМЕНИТЬ И УДАЛИТЬ ИЗ КОДА` для ИИ-агента).

## Архитектура и интеграции

Виджет работает как статичное Frontend-приложение (HTML, JS, TailwindCSS) без собственного бэкенда.

1. **GitHub REST API:** 
   * Прямые `GET` и `PUT` запросы для чтения и перезаписи файлов `.md` в папке `docs/`.
   * Загрузка медиафайлов (Base64) в директорию `docs/media/`.
   * Управление чекбоксами и удаление задач происходит на уровне работы со строками Markdown напрямую через GitHub API, что исключает лишние затраты токенов.
2. **OpenAI API (gpt-4o-mini):** 
   * Задействуется только при генерации новых идей.
   * Системный промпт содержит полный контекст проекта VEI для точной разбивки архитектуры.
3. **Web Speech API:** 
   * Нативная транскрибация голоса в текст прямо в браузере.
4. **Local Storage:** 
   * Локальное и безопасное хранение API-ключей (OpenAI, GitHub), названия репозитория и списка созданных веток на устройстве пользователя.

## Рабочий процесс (Workflow)

1. **Генерация:** Пользователь надиктовывает идею или прикрепляет скриншот в виджете с телефона.
2. **Структурирование:** OpenAI формирует структурированный блок задачи с чекбоксами (`- [ ]`) и пушит обновленный Markdown-файл в репозиторий GitHub.
3. **Реализация:** Разработчик синхронизирует проект в VS Code (`git pull`). ИИ-агент (Roo Code, Continue и т.д.) читает файл `docs/vei.md`, пишет код и сам отмечает задачу крестиком (`- [x]`).
4. **Синхронизация:** При следующем открытии виджета статус задачи автоматически обновляется на выполненный.
